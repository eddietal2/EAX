# Exchange.tz

A simple, fast currency converter for Tanzanian and Kenyan shillings.

## What is this?

Need to know how much USD 98,000 TSH is? Use this app to convert currencies in real time. Whether you're dealing with Tanzanian Shillings (TZS), Kenyan Shillings (KES), or other major currencies, Exchange.tz gives you quick and accurate conversions.

## Features

- **Real-time exchange rates** – Get up-to-date currency conversions instantly
- **Tanzanian & Kenyan Shilling support** – Built specifically for TZS and KES conversions
- **Conversion history** – Keep track of your past conversions for easy reference
- **Simple interface** – No clutter, just the rates you need
